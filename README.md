# Smart Pantry Manager

**Module:** Mobile App Development 700 — Practical Assignment
**Institution:** Richfield Graduate Institute of Technology
**Platform:** Android (Java)

## Database Choice: SQLite
I choose SQLite(using 'SQLiteOpenHelper') over Firebase or PostgreSQL

## Setup / Run Instructions
1. Install **Android Studio** (Hedgehog /2023.1.1 or newer).
2. Clone the respository:
  ```
  git clone <repository-url>
  ```
3. Open the project folder in Android studio.
4. Let Gradle sync.
5. Run on an emulator(API 24+) or a physical device.

## Testing
Unit tests for the strict matching engine live in  `app/src/test/java/com/example/smartpantry/matchingtest.java` and can be run with `Run > Run 'Matchingtest'`
